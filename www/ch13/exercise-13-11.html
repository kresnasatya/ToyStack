Exercise 13-11 — scroll-behavior: smooth

In ToyStack: press the down / up arrow keys. The scroll should glide about 100px over a dozen frames instead of jumping.

In a real browser: arrow keys are often smooth already, so use the links instead — with scroll-behavior: smooth, fragment jumps glide. Try: jump to the middle or jump to the end.

1 / 8

Press the down arrow once. One smooth glide, no jump.

2 / 8

Now mash the down arrow. Each press retargets the in-flight animation, so presses accumulate into one longer glide.

3 / 8

Watch the scrollbar thumb while gliding: it should move smoothly, not in 100px steps.

4 / 8 — the middle

If you got here via the link: a real browser glided the whole way; ToyStack jumps (animating fragment links is a follow-up).

Back to top — in a real browser this is a long, very visible glide.

5 / 8

Press the up arrow: same glide, reversed. Mashing up also accumulates.

6 / 8

Mix directions: press down, then immediately up. The animation retargets from where it was heading, not from where it started.

7 / 8

Control test: delete scroll-behavior from the body tag and reload. Arrow keys go back to instant 100px jumps, and links snap with no glide.

8 / 8 — the end

Scrolling past here clamps at the document bottom, even if a glide is still in flight.
