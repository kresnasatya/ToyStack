Granular style invalidation

opacity and color are paint-only. width and font-size must reflow only their own block and the boxes below them. Colors used here all exist in BrowserColor.swift.

opacity 0.3 ↔ 1.0 — paint only, no layout work.
color purple ↔ tomato — paint only, no layout work.
width 240px ↔ 420px — this sentence rewraps as the box grows, so its own inline block must rebuild and the boxes below move.

font-size 14px ↔ 24px — this paragraph's line height grows, so the text metrics and the boxes below must update.

static box A — layout must be skipped unless a box above changes height.
static box B — no style change, so no child-list rebuild.
static box C — identity and position are the oracle for the trace.
